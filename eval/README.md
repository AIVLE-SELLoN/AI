현재 수치가 아니라 **이 앵커를 제거했을 때의 상한**이며, 오탐이 전부 그 템플릿에서 나온다는
사실이 오히려 그 경고의 근거다. 따라서 few-shot 유출은 프롬프트 예시를 바꾸는 대신
평가에서 거르는 방향으로 처리한다(노션 [실험③ 지표 재설계] §6).

⚠️ **표본 설계 주의** — `--only-negative`는 부정 N + 비부정 N을 균형 추출한다(PR
리뷰 반영, 2026-08-05). 부정만 뽑으면 fp·tn이 구조적으로 0이 되어 "모든 문의를
부정으로 뭉개는" 모델도 precision 100%가 나오는 함정이 있었다 — 지금은 FPR까지
같이 측정된다(`tests/test_run_classify_eval.py`에 회귀 테스트로 고정됨).

⚠️ **전체 실행의 55건 무응답은 배치 실패**(API 처리 중 토큰/연결 문제로 일부 청크
누락)이지, 프롬프트나 채점 로직 문제가 아니다 — `run_classify_eval.py`가 실패

## 비용 통제 4원칙

1. **반복 실험은 oracle 모드로** — 정답 라벨을 직접 입력해 LLM 을 안 태운다 ($0)
2. **분류는 배치 호출** — 건당 호출하면 비용 2배 + 속도 제한 초과
3. **분류 결과는 시드별 캐싱** — 같은 걸 두 번 돌리지 않는다
4. **모델 티어링** — 호출 많은 분류는 저가 모델, 호출 적고 중요한 개선안 생성만 상위 모델

## 원칙

- **`data/golden/` 은 `eval/` 만 읽는다.** `app/` 코드가 import 하면 컨닝이다.
  - 예외 1건: **`scripts/golden_inputs.py`** (2026-08-06 신설). `app/batch/daily.py` 가
    골든을 직접 읽고 있던 것을 `app/` 밖으로 뺀 것이다. 배치를 평가·재현으로 돌릴 때만
    `--input-source golden` 으로 주입하고, 그러면 요약이 oracle 경고를 함께 낸다.
    `app/` 은 여전히 `data/golden/` 을 읽지 않는다 — 원칙 위반이 아니라 원칙을 지키려고
    만든 파일이므로 지우지 말 것. rawDB `classified_item` 이 생기면 역할이 사라진다.
- **재현 가능해야 한다** — 결과와 함께 **실행일·모델명·프롬프트 버전·시드·표본 수 n**
  다섯 개를 반드시 기록할 것. 하나라도 빠지면 발표에 못 쓴다.
- **분모를 밝힐 것.** "100%"가 아니라 "15/15 (100%)"로.
- **정답지를 우리 코드로 만들지 말 것.** 채점 대상으로 정답을 만들면 자기 코드로
  자기를 채점하는 순환이 된다 (①의 `build_golden_anomaly.py` 참고).
- **오답 문장을 이 문서에 적지 말 것.** 유형·건수까지만 쓴다. 이 문서는 커밋되므로
  적는 순간 프롬프트 작성자가 그것을 보고 few-shot 예시를 만들게 되고, 그러면
  `mock data 정의서` §672("few-shot 예시는 평가셋 밖에서 작성 — 시험지 유출 금지")가
  깨진다. 2026-08-06 에 실제로 일어났고(②절 참고), **그렇게 만든 예시는 효과가 없었다.**
  문장이 필요하면 각자 `--diagnose` 를 돌린다 — LLM 0회다.

## ①의 정답지 만들기

`data/golden/golden_anomaly.csv` 는 손으로 쓰지 않고 생성한다:

```bash
python scripts/build_golden_anomaly.py           # config_anomaly.csv → golden_anomaly.csv
python scripts/build_golden_anomaly.py --dry-run # 파일 안 쓰고 요약만
```

⚠️ **이 생성기는 `app/detection` 을 쓰지 않는다.** 정답의 출처는 오직
`config_anomaly.csv` 의 `intended_answer`(설계 의도)다. 사람이 정해야 하는 칸은
채우지 않고 비운 채 실행 시 리포트한다 — 추측으로 채우면 채점이 무의미해진다.

산출물은 120행/38케이스, 채점 대상 31케이스로 mock 정의서 §7 "실질 표본 31케이스"와
일치한다.
