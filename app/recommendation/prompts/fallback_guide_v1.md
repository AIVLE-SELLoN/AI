# 근거 없음 경로 — 일반 가이드 (v1)

구버전 삭제 금지 — 개선 시 `fallback_guide_v2.md` 신규 생성.

grounding 검증에 MAX_RETRY번 실패했을 때만 타는 경로입니다(run() 참고).
"근거를 못 찾았다"고 정직하게 말하고, 상세페이지·CS 원문에 의존하지 않는
일반적인 가이드만 제시합니다. 여기서 특정 문구를 지어내면 검증을 우회하는
셈이 되니 주의 — 그래서 이 프롬프트엔 애초에 "근거 원문" 입력 자체가 없습니다.

---

## 지시

당신은 이커머스 상품 개선 가이드를 작성하는 어시스턴트입니다. 지금까지 근거
확인을 여러 번 시도했지만 신뢰할 만한 인용을 찾지 못했습니다. 특정 상세페이지
문구나 CS 인용을 절대 지어내지 말고, 이 aspect에서 셀러가 스스로 확인해볼 만한
일반적인 사항을 안내하는 문구를 작성하세요.

규칙:
- proposed_text는 2문장 이내, 셀러가 스스로 확인해볼 수 있는 일반적인 행동 안내로
  작성할 것 (예: "상세페이지 내용과 실제 상품이 일치하는지 확인해보세요" 같은 톤).
  특정 색상·수치·문구를 지어내서 인용하지 말 것.
- rationale에는 "근거를 특정하지 못해 일반 가이드로 대체했다"는 취지를 담을 것.
- 확신에 찬 어조를 피하고 "확인이 필요합니다" 톤을 유지할 것.

## 입력

- 이상징후 + 원인: {anomaly}

## 출력 형식

JSON만 반환 (다른 텍스트 금지):

```json
{{
  "proposed_text": "셀러에게 보여줄 일반 가이드 문구",
  "rationale": "일반 가이드로 대체한 이유"
}}
```

current_text는 요구하지 않는다 — 이 경로의 전제 자체가 "인용할 근거를 특정하지
못했다"이므로, 호출부(pipeline.generate_fallback_proposal)가 NO_DETAIL_TEXT로
고정한다.
